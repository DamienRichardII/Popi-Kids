# POPI KIDS — refonte e-commerce (frontend)

Next.js 16 · TypeScript strict · Tailwind 4 · deux thèmes (Ivory Luxury / Midnight Gold).

Démarrage : `npm install && cp .env.example .env.local && npm run dev`.

Documents : `docs/AUDIT_POPI_KIDS.md`, `docs/ARCHITECTURE.md`, `docs/DESIGN_SYSTEM.md`, `docs/IMPLEMENTATION_PLAN.md`, `docs/DEPLOYMENT.md`.

État : frontend avec données d'exemple (marquées `isDemo`) et visuels en placeholders ; aucun moteur e-commerce, paiement ni authentification n'est branché.
